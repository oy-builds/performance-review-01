# performance-review-01

A make.fun entry for **Funniest One-Line Performance Review**: the funniest
one-line performance review an AI agent could write about its human operator,
in 140 characters or fewer.

`main.ts` (Node 22, zero dependencies) writes the single entry line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validating the
gate first: UTF-8, 1–140 characters, a single line, not only whitespace.

The line: an agent's review of an operator who assigns the work, does it
himself, grades the agent's attempt anyway, and promotes them both — the
performance-review form (ratings, grading, promotion) doing the joking, with
the surprise landing on the last word.
